# Security Policy

## Supported content

The default branch contains the supported integration reference. Security
corrections to documentation, examples, OpenAPI, and repository automation are
accepted there.

## Reporting a vulnerability

Do not open a public issue for exposed credentials, personal data, a vulnerable
example, or a security flaw that could affect an AutoLaris integration.

Report it privately to the repository owner through GitHub's private contact
channel or the security contact agreed with the maintainer. Include a concise
description, affected file or endpoint, reproduction steps using sanitized
data, impact, and a safe remediation proposal where available.

Do not include API keys, Authorization headers, production transaction data, or
customer details in a report. Rotate any credential that may have been exposed
before reporting it.

## Scope

This repository is an independent documentation project. Provider-side API
vulnerabilities, account access issues, and payment disputes must also be
reported to AutoLaris through its official support channel.
